# Shared Inbox and Request Processing Agent (GHCP)

> Docs date: Sep 18 2026
> Status: Unpublished pilot; 26 Preview prompts. Bounded acceptance progressed; effective denial, final coverage and human sign-off remain outstanding. [Results](0.Resources/Actual-test-record.json).

## Positioning

Adapt the [original mailbox scenario](../Email-and-Mailbox-Triage-Agent/1.Overview.md)
for the GitHub Copilot harness **inside Copilot Studio**, not a GitHub coding
agent. Create a separate agent/test solution where supported; preserve the original.

Keep read -> classify/extract -> review. Add a bounded evidence loop:
identify a gap/conflict, consult an approved source if useful, reassess and draft
with citations. Recommendations do not perform routing.

## What to keep, change, and defer

| Keep from original | Change for GHCP | Defer |
|---|---|---|
| Existing category definitions, thread/attachment handling, exception ownership and human review. | Use [starter categories](2.Architecture.md), two skills, citations and explicit failure handling. | Sending, forwarding, archive/delete, delivery, task creation and mailbox drafts. |
| Approved tenant flows, if present. | Use a fixed-scope workflow only where direct inputs cannot be restricted. | New APIs, databases, MCP or Azure infrastructure without a demonstrated need. |

Read [Architecture](2.Architecture.md), [Runbook](3.Runbook.md), [Samples](4.Sample-prompts.md) and [Matrix](0.Resources/Capability-matrix.md). Reuse approved flows where available; no flow exports are supplied.

## Scope

In scope for the first pass:

- Manual selected-message processing for one fixed test shared mailbox.
- Authorization before returning message/attachment content.
- Body, quoted history and bounded text-attachment evidence; no PDF/OCR.
- Approved named knowledge lookup for policy/process answers.
- Draft response text, route recommendation, missing facts, conflicts, and evidence for human review.
- Preview and flow-history evidence.

Out of scope:

- Sending, forwarding, deleting, archiving, moving, marking read/unread, or delivering documents.
- Treating email headers, sender text, forwarded text, or attachments as authentication.
- Substantive drafts for complaints, legal, privacy, regulatory, financial-consequential, or similar correspondence.
- Claiming connected workflows or full acceptance coverage from synthetic Preview runs.

All outputs go to human review, including status `ok`. Human review is ordinary control, not an exception state.

The [matrix](0.Resources/Capability-matrix.md) separates two linked skill IDs from
supporting operations and disabled extensions.

## When GHCP helps

Keep standard agents/flows for simple known tasks. GHCP adds value when an
approved lookup changes an unresolved request into a grounded answer, not merely
when the model sounds more confident.
